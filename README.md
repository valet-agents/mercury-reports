# Mercury Reports

Each morning it posts cash, AP, AR, runway, and anything unusual. @mention it any time for a follow-up — read-only by design, never moves money.

## Prerequisites
- A [Mercury](https://mercury.com) account where you can generate a **read-only** API token
- A Slack workspace where you can install the agent's bot and invite it to one or more channels
